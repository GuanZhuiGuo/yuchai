# 玉柴销售学习中心 H5 Demo

面向玉柴销售人员的移动学习平台。课程采用视频、图文讲义与自检；一门课程关联多个客户实战场景。学员可直接进入已发布且服务可用的实战，自由作答，结束对话后查看评价依据，再回到对应方法复习。学习进度用于记录和推荐，不限制实战入口。

## 本地打开

[学习平台](http://127.0.0.1:5317/) 仅在运行服务的这台电脑有效。桌面提供学方法、练实战、看报告的导航，手机呈现学员界面。导航不会载入虚构学习进度。

建议演示路径：

1. 在首页进入一门课程，播放微课，点击重点定位，阅读三个图文章节并完成自检。视频有效观看达到 90%、各节已读、自检正确后，本课完成。
2. 在课程页查看 2–3 项关联实战。不同客户场景可以复用同一门课；同一实战也可关联多门课。课程详情和实战中心均可直接进入已发布且服务可用的任务，无需先完成课程、视频或自检。
3. 进入已发布任务，选择文字或语音作答。商用车场景默认文字，无需麦克风。切换到语音后，消息对话点击“点击说话”开始录音，点击“点击发送”提交本轮，随后可继续下一轮；实时对话点击“开启实时对话”后连续输入，可暂停和继续。麦克风由语音主按钮直接申请，连接 AI 客户时不自动录音。关联实战卡片和准备页分别标记“消息对话”或“实时对话”，会话按服务端返回的模式连接。客户朗读默认开启，可随时关闭；浏览器阻止自动播放时提示学员点击开启声音。海外场景当前默认语音，文字通道标记待恢复。
4. 主动结束对话，等待陪练服务生成实际报告；查看维度、原文证据与复习推荐。评估尚未完成或请求失败时不显示成绩。
5. 从报告回看课程并再次进入实战。报告区另有 75 分固定参考样例，仅说明完整拜访报告结构，不计入实际成绩。

## 课程和媒体

五门课程覆盖开场信任、需求与决策链、适配/TCO/服务、异议与风险、谈判/推进/海外准入，共七个拜访阶段。

媒体包含六张玉柴官方业务照片和三段原创示范微课，时长分别为 99.13、94.42、89.54 秒，采用火山引擎豆包云舟合成配音、画内字幕及独立 VTT。c1/c2 复用需求片，c3/c4 复用价值片，c5 使用海外准入片。视频标题标记教学关联，课程图文保留各自目标与自检。微课为教学演示，不属于玉柴录播培训资料。

照片用于业务情境配图，来源及语义范围见 [媒体来源](research/媒体来源.md)。经销商照片来自 2024 年西亚参访，不能认作本轮东南亚考核现场；新加坡图片是新闻中的城市情境照。照片不能证明某项产品参数或商务承诺。

建议图文学习时长合计 38 分钟是规划参考。学习进度保存在当前浏览器，正式企业学习记录需要服务端管理。重置本地进度保留远端实战记录。

## 启动

需 Node.js 20.12 或更新版本。

```sh
npm install
npm run build:voice
npm start
```

固定本机 `127.0.0.1:5317`、项目 `5`、学员 `1`。`PORT` 可设置其他本机端口。真实陪练需要 `SPARRING_OPENAPI_ACCESS_KEY` 和 `SPARRING_OPENAPI_SECRET_KEY`。本机启动时自动读取工程根目录的 `.env.local`，已有进程环境变量优先；可参照 `.env.example` 填写并将文件权限设为 `600`。凭证仅供服务端使用，配置文件不纳入版本管理，交付包不包含实际凭证。云端仍可通过进程环境注入配置。

源码仓库包含运行代码、课程媒体、部署脚本和合成报告测试数据。原始客户资料、调研过程、接口联调记录、截图和发布包保留在本机，不纳入 Git。下文 `research/` 和 `evidence/` 的过程材料引用用于说明本机验证来源，媒体来源说明随仓库提供。代码检查使用 `npm run check`，回归测试使用 `npm test`，测试不需要真实接口密钥或麦克风。

缺少环境变量时仍可浏览课程、媒体、自检、规划任务和参考报告，实际陪练不可启动。云端演示采用 `/yuchai-training/` 子路径，页面和课程公开浏览，真实接口与报告通过现有门户登录检查；服务仅监听本机，Nginx 固定回源 Host，并以 `PUBLIC_ORIGIN` 精确校验作答和 WebSocket 来源。麦克风需要 HTTPS。演示固定使用项目 5、账号 1，门户登录不代表已完成企业学员身份映射；正式部署需学员权限、服务端学习记录与配置管理。

## 语音交互验证（2026-10-10）

录音和播放 AudioWorklet 使用同源静态模块，适配当前云端 CSP，无需放宽脚本安全策略。实时录音采用设备原生采样率，在录音模块中重采样为 16 kHz。录音设备、权限、音频处理与对话连接错误分别呈现；语音初始化失败时保留对话连接与重试入口。

14 项语音及部署检查通过。在与云端相同的 CSP 下，浏览器确认旧 Blob 模块被拦截、同源录音及播放模块加载成功，并从合成静音源获得 5,120 字节 PCM 帧。桌面消息录音与手机实时聆听界面在隔离 UI 验证页检查；该页面未创建真实实战记录。上述检查未采集真人麦克风。
